1. Técnica: Outro
2. Algoritmo: Busca em Largura (BFS)
3. Autores: Sem atribuição histórica nesta ficha
4. Data: Não especificada nesta ficha
5. Conceitos: Grafo, Matriz, Fila, Distância, Predecessores
6. Problema: Busca: Encontrar os vértices alcançáveis e a menor quantidade de arestas entre uma origem e cada um deles.
7. Complexidade: O(V²)

A busca em largura visita primeiro a origem, depois os vértices a uma aresta dela, depois os que estão a duas arestas, e assim por diante. Para manter essa ordem, usamos uma fila: o primeiro vértice que entra é o primeiro a sair.

Quando descobrimos um vizinho y de x, registramos dist[y] = dist[x] + 1, guardamos pai[y] = x e colocamos y no fim da fila. Marcamos y nesse momento, antes de retirá-lo da fila, para impedir inserções repetidas.

Implementação em C: grafo[x][y] vale 1 quando há uma aresta de x para y. Os vértices vão de 0 até V-1, e todas as arestas têm o mesmo custo.

@c
#define V 6

void busca_largura(int grafo[V][V], int origem, int dist[V], int pai[V]){
    int fila[V];
    int inicio = 0, fim = 0;
    for (int x = 0; x < V; x++) {
        dist[x] = -1;
        pai[x] = -1;
    }
    if(origem < 0 || origem >= V)return;
    dist[origem] = 0;
    fila[fim++] = origem;
    while(inicio < fim){
        int x = fila[inicio++];
        for(int y = 0; y < V; y++){
            if(grafo[x][y] && dist[y] == -1){
                dist[y] = dist[x] + 1;
                pai[y] = x;
                fila[fim++] = y;
            }
        }
    }
}
@c

inicio aponta para o próximo elemento a sair, e fim aponta para a próxima posição livre. Como cada vértice entra uma única vez, um vetor com V posições basta para esta execução; não precisamos de uma fila circular.

dist[x] igual a -1 significa que x ainda não foi descoberto. Ao final, significa que ele não é alcançável a partir da origem. pai[x] permite reconstruir um caminho voltando do destino até a origem; para imprimi-lo no sentido correto, podemos guardar essa sequência em uma pilha.

Por exemplo, com arestas não dirigidas 0-1, 0-2, 1-3, 2-4 e 4-5, as distâncias a partir de 0 são {0, 1, 1, 2, 2, 3}. Um caminho até 5 é 0, 2, 4, 5.

O invariante é que a fila mantém os vértices em ordem não decrescente de distância. Assim, a primeira descoberta de um vértice já determina sua menor distância em número de arestas. Para pesos diferentes, essa garantia não resolve o problema geral de menor custo.

Com matriz de adjacência, o pior caso custa O(V²). Com listas de adjacência, custa O(V+E). A fila e os vetores auxiliares usam O(V) de memória, além da representação do grafo.
