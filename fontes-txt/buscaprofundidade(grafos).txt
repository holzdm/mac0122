6. Problema: Busca: Visitar os vértices alcançáveis a partir de uma origem em um grafo.
7. Complexidade: O(V²)

A busca em profundidade visita um vértice e continua por um vizinho ainda não visitado. Antes de tentar outro vizinho do vértice inicial, ela explora os caminhos que partem desse primeiro vizinho. Quando não existem novos vizinhos, a função retorna à chamada anterior e continua a exploração.

É necessário marcar o vértice antes de explorar seus vizinhos. Isso impede que um ciclo provoque chamadas repetidas indefinidamente. A pilha de chamadas da recursão guarda os vértices cuja exploração ainda não terminou.

Usaremos grafo[x][y] igual a 1 quando existir uma aresta de x para y. Em um grafo não dirigido, preenchemos também grafo[y][x]. Os vértices são numerados de 0 até V-1.

Implementação em C:

@c
#include <stdio.h>
#define V 6

void dfs(int grafo[V][V], int x, int visitado[V], int pai[V]){
    visitado[x] = 1;
    printf("%d ", x);
    for(int y = 0; y < V; y++){
        if(grafo[x][y] && !visitado[y]){
            pai[y] = x;
            dfs(grafo, y, visitado, pai);
        }
    }
}

void busca_profundidade(int grafo[V][V], int origem, int visitado[V], int pai[V]){
    for(int x = 0; x < V; x++){
        visitado[x] = 0;
        pai[x] = -1;
    }
    if(origem < 0 || origem >= V)return;
    dfs(grafo, origem, visitado, pai);
}
@c

visitado[x] informa se x já foi descoberto. pai[y] registra qual vértice descobriu y; a origem e os vértices não alcançados permanecem com pai igual a -1. A condição !visitado[y] garante que cada vértice seja descoberto uma única vez.

Por exemplo, com arestas não dirigidas 0-1, 0-2, 1-3 e 2-4, a busca iniciada em 0 imprime 0 1 3 2 4. O vértice 5 não é alcançado. A ordem depende da ordem em que os vizinhos são examinados.

Para percorrer todo o grafo, inclusive componentes desconexas, inicializamos os vetores uma única vez e chamamos dfs para cada vértice ainda não visitado. Não reinicializamos os vetores entre essas chamadas.

Com matriz de adjacência, cada vértice visitado exige examinar V posições: o pior caso custa O(V²). Com listas de adjacência, custa O(V+E), em que E é o número de arestas. A memória auxiliar, incluindo a recursão, é O(V), além da representação do grafo. A DFS não garante o caminho com menor número de arestas.
