1. Técnica: Método Guloso
2. Algoritmo: Kruskal (árvore espalhada mínima)
3. Autores: Joseph Kruskal
4. Data: 1956
5. Conceitos: Grafos, Árvores, recursividade, árvore espalhada mínima
6. Problema: Dado um grafo não direcionado com custos nas arestas, determinar a árvore geradora de menor custo

Se temos um grafo não direcionado com pesos nas suas arestas, queremos descobrir a árvore geradora de menor custo (ou seja, cuja soma
dos custos das arestas é mínimo). Para isso, vamos analisar a construção de um grafo por um algoritmo guloso em que, a cada passo, 
escolhemos uma aresta para adicionar no grafo. 
Para fazer essa escolha, vamos utilizar o seguinte raciocínio:
1) Toda árvore tem exatamente n-1 arestas, onde n é o número de vértices;
2) A árvore tem que ser conexa;
Isso nos permite concluir que, em um determinado passo, a melhor decisão é escolher a aresta de menor custo que une duas componentes conexas. Isso porque, primeiro, se tenho uma aresta que não liga duas componentes conexas, então ela é descartável (já que, necessariamente, conecta dois vértices da mesma componente). Segundo, se tenho um conjunto de opções de arestas que liga duas componentes conexa, posso minimizar o custo tomando simplesmente a de menor custo.
Desse modo, a ideia do algoritmo é a seguinte:
1) Ordenamos as arestas em ordem crescente de custo;
2) Em um dado passo do algoritmo, escolhemos a aresta de menor custo que liga duas componentes conexas para adicionar;
Ordenar as arestas é simples. Precisamos, agora, identificar uma boa forma de encontrar componentes conexas. Vamos, então, adicionar a estrutura de dados Union-Find. A ideia da estrutura se baseia nas funções Union e Find, que funcionam da seguinte forma:
a) Find: Para um certo vértice v, ao utilizar find(v), a função deve devolver o nome da componente conexa a que v pertence.
b) Union: Para conjuntos A e B (ou seja, componentes conexas A e B), ao utilizar union(A, B), a função deve mudar a estrutura de modo que os conjuntos A e B sejam unidos em um só.
Vamos implementar isso definindo um vetor "Famílias" de n posições em que, na posição i, damos o nome do conjunto do vértice i. De início, definimos que para todo i o conjunto de i é chamado de i (pois as componentes conexas são todas de um vértice, tem tamanho 1). Então, de modo bem simples, a função find(v) vai devolver a posição v do vetor. 
Já union vai comparar os conjuntos A e B: como a única ação que toma mais do que O(1) numa união é a mudança dos valores no vetor, faz sentido minimizar essa ação definindo que, dados conjuntos A e B, se |A|>|B|, mudamos todos os vértices em B para em A, pois realizamos o menor número de operações. Como o tamanho é demorado para calcular na hora (precisaríamos fazer uma busca), vamos fazer um vetor "tamanho" que guarda o tamanho de cada componente conexa, de modo que tamanho[c] representa o tamanho da componente c. Então, union é uma operação que muda nosso vetor. É interessante, também, fazer uma função que inicializa o nosso vetor com familia[i] = i para todo i.
Veja a implementação das funções em C:

//Essa função inicializa o vetor:

void inicializa(int familia[], int tamanho[], int n) {
    for (int i = 0; i < n; i++) {
        familia[i] = i; // no começo, cada vértice é sua própria família
        tamanho[i] = 1;  // cada componente começa com tamanho 1
    }
}

//Já para o find podemos só tomar a família de v:

familia [v]

//Por fim, a union:

void union_f(int familia[], int tamanho[], int n, int A, int B) { //union é palavra reservada
    if (A == B) return;
    int maior, menor;
    if (tamanho[A] >= tamanho[B]) {
        maior = A;
        menor = B;
    } else {
        maior = B;
        menor = A;
    }
//aqui em cima já conseguimos quem é maior ou menor
    for (int i = 0; i < n; i++) {
        if (familia[i] == menor) {
            familia[i] = maior;
        }
    }
//aqui varremos o vetor todo e mudamos quem é do menor para ser do maior
//na próxima, vamos só mudar os tamanhos, pois somamos os dois agora, já que unimos
    tamanho[maior] += tamanho[menor];
    tamanho[menor] = 0;
}

Por fim, podemos implementar o algoritmo de Kruskal da seguinte forma:

1) Ordenar as arestas em custo, podemos usar qualquer ordenador aqui;
2) Inicializar o vetor do union-find;
3) Percorrendo as arestas (seja A(v, w) a aresta que liga v e w) em ordem crescente de custo, até adicionar n-1 arestas no grafo, faça: 
  3.1) Se familia[v] != familia[w]:
    3.1.1) Adicione A(v, w) no grafo;
    3.1.2) Faça union_f(familia[v], familia[w]);

Para facilitar a implementação, faz sentido definir um struct com a aresta e seu custo;
Implementação em C completa:

#include <stdio.h>
#include <stdlib.h>
typedef struct {
    int v;
    int w;
    int custo;
} Aresta;

int comparar_arestas(const void *a, const void *b) {
    Aresta *arestaA = (Aresta *)a;
    Aresta *arestaB = (Aresta *)b;
    return arestaA->custo - arestaB->custo;
} //a ideia aqui é trazer os custos das arestas. Como esse comparador é usado na qsort, ele precisa do const void. Porém, o foco do código não é a ordenação, e sim o Kruskal abaixo

void kruskal(int n, int m, Aresta arestas[]) { // Aresta arestas[] é um vetor de arestas
    int familia[n];
    int tamanho[n];
    Aresta arv_min[n - 1]; // guarda as arestas da árvore geradora mínima

    // 1) Ordenar as arestas em ordem crescente de custo
    qsort(arestas, m, sizeof(Aresta), comparar_arestas); //como no caso o foco não é a ordenação em si, ao invés de montar um algoritmo (que poderia ser o de escolha do usuário), utilizei a função nativa do C qsort, que já resolve o problema

    // 2) Inicializar o vetor do union-find
    inicializa(familia, tamanho, n);

    // 3) Percorrer as arestas em ordem crescente até adicionar n-1 arestas
    int arestas_adicionadas = 0;
    int custo_total = 0;

    for (int i = 0; i < m && arestas_adicionadas < n - 1; i++) {
        int v = arestas[i].v;
        int w = arestas[i].w;

        int fam_v = familia[v];
        int fam_w = familia[w];

        // 3.1) Se familia[v] != familia[w]
        if (fam_v != fam_w) {
            // 3.1.1) Adicione A(v, w) no grafo (árvore resultante)
            arv_min[arestas_adicionadas] = arestas[i];
            arestas_adicionadas++;
            custo_total += arestas[i].custo;

            // 3.1.2) Faça union_f(familia[v], familia[w])
            union_f(familia, tamanho, n, fam_v, fam_w);
        }
    }

if (arestas_adicionadas < n - 1) {
        printf("O grafo original nao e conexo; nao existe arvore geradora.\n");
    } else {
        printf("Arestas da Arvore Geradora de Menor Custo:\n");
        for (int i = 0; i < n - 1; i++) {
            printf("(%d, %d) - custo: %d\n", arv_min[i].v, arv_min[i].w, arv_min[i].custo);
        }
        printf("Custo total minimo: %d\n", custo_total);
    }
}

int main() {
    int n, m;

    if (scanf("%d %d", &n, &m) != 2 || n <= 0 || m < 0) {
        printf("Entrada invalida.\n");
        return 1;
    }

    Aresta *arestas = (Aresta *)malloc(m * sizeof(Aresta));
    if (m > 0 && !arestas) {
        printf("Erro ao alocar memoria para as arestas.\n");
        return 1;
    }

    for (int i = 0; i < m; i++) {
        if (scanf("%d %d %d", &arestas[i].v, &arestas[i].w, &arestas[i].custo) != 3) {
            printf("Erro na leitura da aresta %d.\n", i + 1);
            free(arestas);
            return 1;
        }
    }

    kruskal(n, m, arestas);

    free(arestas);
    return 0;
}
