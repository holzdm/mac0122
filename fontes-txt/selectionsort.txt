1. Tecnica: Guloso
2. Algoritmo: Insertion Sort (implementação em vetores) 
3. Autores: Konrad Zuse 
4. Data: 1945
5. Conceitos: vetor
6. Problema: Dada uma sequência de números, obter um vetor ordenado que contenha todos os índices da sequência (qualquer índice do vetor é menor ou igual ao próximo, se houver).

O algorítmo selectionsort acha o menor elemento do vetor e troca ele diretamente com o elemento de primeiro índice. Partindo de um vetor desordenado, ele considera o primeiro elemento como subvetor (um vetor unitário sempre está ordenado). A partir disso, ele percorre o vetor e compara cada elemento com o menor elemento do seu subvetor (o primeiro). Ao terminar de percorrer o vetor, foi obtido o indice do menor elemento. Se esse índice for diferente de i (ou seja, existe um número menor que i), eles trocam de posição. Assim, o invariante desse algorítmo é: Na n-ésima iteração, existe um subvetor com os menores n-1 elementos do vetor, já ordenados. 
Como o algorítmo itera para todos os índices do vetor, e a cada iteração o vetor é percorrído até o final, a complexidade desse algorítmo é O(n²). 


@c
void selectionsort(int *v, int fim){
    for(int i=0;i<fim-1;i++){
        int min = i;
        for(int j=i+1; j<fim-1; j++){
            if(v[j]<v[min]) min = j;
        }
        if(min != i){
            int aux = v[i];
            v[i]=v[min];
            v[min]=aux;
        }
    }
}
