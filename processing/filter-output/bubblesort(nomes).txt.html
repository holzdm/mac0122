1. Técnica: Método Guloso
2. Algoritmo: Bubblesort (Ordenação de Nomes)
3. Autores: Adaptação didática, sem atribuição histórica nesta ficha
4. Data: Não especificada nesta ficha
5. Conceitos: Vetor, Ponteiros, strcmp, Ordenação
6. Problema: Ordenação: Colocar uma sequência de nomes em ordem lexicográfica.
7. Complexidade: O(n² L)

O funcionamento é o mesmo do bubble sort para números, mas a comparação precisa usar strcmp. Em C, comparar strings com > ou == compara os ponteiros, não o conteúdo dos nomes.

strcmp(a, b) retorna um valor negativo quando a vem antes de b, zero quando os textos são iguais e um valor positivo quando a vem depois de b. Não devemos supor que os valores retornados sejam exatamente -1 e 1.

Implementação em C: o vetor contém ponteiros para strings válidas e terminadas em '\0'. A função troca os ponteiros no vetor, sem alterar os caracteres das strings.


#include <string.h>

void bubblesort_nomes(const char *nomes[], int n){
    for(int fim = n; fim > 1; fim--){
        int trocou = 0;
        for(int i = 0; i < fim - 1; i++){
            if(strcmp(nomes[i], nomes[i + 1]) > 0){
                const char *aux = nomes[i];
                nomes[i] = nomes[i + 1];
                nomes[i + 1] = aux;
                trocou = 1;
            }
        }
        if(!trocou)break;
    }
}


Exemplo de chamada:


const char *nomes[] = {"Carlos", "Ana", "Bruno", "Ana"};
bubblesort_nomes(nomes, 4);


O resultado é {"Ana", "Ana", "Bruno", "Carlos"}. Ao final de cada passagem, o maior nome do intervalo ainda em análise está em sua posição definitiva. Se uma passagem não realiza trocas, o vetor já está ordenado e podemos encerrar.

A comparação usa > 0, e não >= 0. Portanto, nomes iguais não são trocados entre si e o algoritmo é estável.

Se L é o maior comprimento de um nome, cada comparação pode custar O(L). O pior caso custa O(n²L); com a verificação de trocou, um vetor já ordenado custa O(n L). A memória auxiliar é O(1), pois trocamos somente ponteiros.

strcmp usa a ordem dos bytes, distingue maiúsculas e minúsculas e não implementa a ordem alfabética própria do português para nomes acentuados. Aqui, ordem lexicográfica significa a ordem definida por strcmp.
