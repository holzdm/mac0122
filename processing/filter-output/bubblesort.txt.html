5. Conceitos: Vetor
6. Problema: Ordenação: Dada uma sequência de números, obter um vetor ordenado que contenha todos os índices da sequência (qualquer índice do vetor é menor ou igual ao próximo, se houver).
7. Complexidade: O(n²)


O algorítmo bubblesort funciona por meio de iterações. A cada iteração, o elemento de indice i do vetor v é comparado com o próximo. Se esse elemento é maior que o próximo, então os dois trocam de lugar, e o iterador avança uma posição no vetor (i++) até chegar ao fim do vetor. Ao final de cada iteração, o invariante é que o maior elemento do vetor está na última posição dele. Assim, repete-se o processo, agora observando o vetor apenas até a penúltima posição (fim--), de forma que ao fim da iteração o penúltimo índice será o segundo maior. Esse processo se repete até que o tamanho do vetor seja unitário. Nesse momento, o vetor estará perfeitamente ordenado.
Para cada valor de fim (n vezes), o iterador percorre o vetor inteiro e faz 1 comparação por índice (n vezes). Logo, a complexidade desse algorítmo é O(n²).

Implementação em C: a função recebe um ponteiro para vetor e um inteiro que define o último índice que deve ser ordenado. Ela não retorna resultado, apenas altera diretamente o vetor.


#include <stdio.h>
void bubblesort(int *vetor, int fim){
    int aux=0;
    while(fim > 1){
        for (int i = 0; i < fim-1 ; i++){
        if(vetor[i]>vetor[i+1]){
            aux=vetor[i];
            vetor[i]=vetor[i+1];
            vetor[i+1]=aux;
        }
    }
    fim--;
    }
    
}
