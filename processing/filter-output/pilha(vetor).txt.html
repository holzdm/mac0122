1. Técnica: Outro
2. Algoritmo: Pilha (Implementação em Vetores)
3. Autores: Alan Turing (primeiro a tratar de pilhas ) / Friedrich L. Bauer e Klaus Samelson (Isolaram o conceito de pilha como uma estrutura de dados abstrata e autônoma)
4. Data: 1945–1946 / 1957
5. Conceitos: Vetor
6. Problema: Estruturas: criar um metodo de estrutura de dados em que o ultimo elemento a entrar deve ser o primeiro a sair (LIFO)
7. Complexidade: O(1)

Primeiro, devemos definir oque é pilha. Pilha é uma estrutura de dados que permite inserção ou remoção de novos elementos, de maneira que, o último elemento a entrar é, nescessariamente, o primeiro a sair.

Para mostrar a aplicação em um vetor, vamos supor que nossa pilha está em um vetor pilha[0...N-1] e ocupa a parte  pilha[0...k-1]. Logicamente, k-1 indica o topo da lista e, se k = 0 a pilha está vazia, e se k = N, a pilha está cheia.

Para remover um item da pilha, realizaremos a operação desempilhar ( pop ), dada por  : 

   return pilha[--t];


O codigo, basicamente, diminui o valor de t em 1 casa, fazendo com que o ultimo elemento da pilha não faça mais parte dela. 

Para adicionar um item na pilha, usa-se a operação empilhar (push), dada por : 

   pilha[t++] = y;


O codigo aumenta o valor de t em uma casa, e, nesse novo elemento da pilha, coloca y.
