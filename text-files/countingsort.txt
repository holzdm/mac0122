1. Tecnica: frequência
2. Algoritmo: Counting Sort (implementação em vetores) 
3. Autores: Harold H. Seward
4. Data: 1954
5. Conceitos: vetor
6. Problema: Dada uma sequência de números, obter um vetor ordenado que contenha todos os índices da sequência (qualquer índice do vetor é menor ou igual ao próximo, se houver).

O algorítmo counting sort funciona calculando a frequência parcial de todos os ítens dentro de um vetor v[] menores ou iguais ao elemento v[i]. Assim, é possível encaixar o elemento v[i] na posição imediatamente posterior à obtida pela frequência dos predecessores. 
Ele funciona de forma bem diferente dos outros, e seu tempo de execução depende não somente do tamanho do vetor, mas da grandeza dos índices. 

Implementação em C: O algorítmo itera pelo vetor e, a cada índice, usa o valor do elemento como índice para um segundo vetor fp[] (esse segundo vetor será chamado vetor de frequências parciais. Ao fim da primeira iteração, as frequencias de cada elemento i estão em fp[i+1]. Após isso, o algorítmo calcula a frequência acumulada para cada índice.())

void countingsort(int *v, int n, int R){
    int r;
    int *fp, *aux;

    fp=malloc((R+1)*sizeof(int));
    aux=malloc(n*sizeof(int));

    for (r=0;r<=R;r++){
        fp[r]=0;
    }
    for (int i=0;i<n;i++){
        r=v[i];
        fp[r+1]++;
    }
    for (r=1;r<R; ++r)
    fp[r]+=fp[r-1];

    for (int i=0;i<n;i++){
        r=v[i];
        aux[fp[r]]=v[i];
        fp[r]++;
    }   for (int i = 0; i < n; ++i) 
      v[i] = aux[i];

    free (fp);
    free (aux);
}
